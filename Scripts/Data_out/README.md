Data_out

This file contains all the text/csv files from the R script  Scripts > N_Am_Meta_DHD_J-EPC0033278-QP-1-0_20260311_v04.R

Enumerated_boxplot.csv
This file contains the data that was used to make the box plot of the enumerated data and is similiar Figures > Table1_FecalPathDHD_20260226v1.docx except that it also contains the standard error using Rubins Rules and the references that the synthisized meta analysis values is based on.  This was mainly used to keep track of journal articles from the discussion section.

Enumerated_box_display.csv
This file is the raw csv version output that was cleaned up and reformatted for Figures > Table1_FecalPathDHD_20260226v1.docx.

Total_Prevalence_Dataset1.csv
This file has synthesize values for prevalence for all combinations of Pathogen (Enterococcus, E. coli, etc...), Method (Molecular, conventional, immunological) and subgroup or animal class (Bird, North America, etc...).  This file was paired down to create Figure4_FecalPathDHD_20260226v1.tiff.  This file contains pathogens that were not included in the journal articles such as E. coli version EHEC or Campylobacter coli. Also included methods that were not included molecular and immunological.  All of these extra combinations were later excluded from the journal article to reduced the scope of the article because the data did not fit or the comibination met one of the study exclusion criteria.  This file is being retained because this meta-analysis of extra more specific combinations may be of use to future researchers.
